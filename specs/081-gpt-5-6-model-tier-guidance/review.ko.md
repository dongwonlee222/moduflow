## 승인 전에 아셔야 할 것 — 수용된 발견 1건

`COGNITIVE_DEMAND_GUIDANCE`가 **호스트와 무관하게 모든 워커 프롬프트에 무조건 붙습니다.**

Claude Code나 Gemini에서 워커를 돌려도 OpenAI 모델 안내를 받습니다:

```
변경 전:  40자   "use your most capable reasoning model."
변경 후: 190자   "... If using OpenAI GPT-5.6, prefer gpt-5.6-sol; ..."
```

| 단계 | 프롬프트 문구 길이 |
| --- | --- |
| `deep` | 190자 |
| `balanced` | 180자 |
| `fast` | 146자 |

즉 적용될 수 없는 호스트에서도 프롬프트당 **110~150자가 추가로 실립니다.**

**차단 사유로 잡지 않은 이유**: `"If using OpenAI GPT-5.6"`라는 조건부 표현이라 다른 호스트에서 **틀린 건 아니고 그냥 무용지물**입니다. 그리고 이 이슈가 등록한 후속 두 개가 정확히 그 해결책입니다 — `082`가 호스트 인식 라우팅, `084`가 프롬프트 컨텍스트 예산.

→ **이 발견이 `082`를 `083`보다 먼저 해야 하는 구체적 근거입니다.**
