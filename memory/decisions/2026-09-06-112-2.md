# 112: 섹션 제외는 이름 전체 일치, 끝난 작업 의존은 충족, 파일 겹침은 경로 포함관계로 본다

## Summary

결정 2·3·4 승인. 판단이 아니라 확인 — 셋 다 틀린 답이 이미 측정됐거나(2·4) 이미 그렇게 동작 중(3).

## Rationale

2: 부분 문자열 일치로 제외하면 'Stream 3 — Tests + verification (gate)' 아래 진짜 테스트 작성 작업 4개가 삭제된다(측정됨). 이름 전체 일치로 한다. 3: 끝난 작업에 대한 의존은 충족으로 친다 — 이미 shipped 동작이며, 아니면 앞 작업이 끝나도 뒤 작업이 영영 안 풀린다. 4: 파일 겹침을 문자열 비교로 보면 scripts/* 와 scripts/ 아래 4개 파일이 '안 겹친다'로 판정돼 워커 둘이 같은 파일에 붙는다(명세 027에서 측정됨). 경로 포함관계로 비교하고, 공유 상태를 건드리면 나누지 않고 inline으로 간다.

## Evidence

specs/112-execution-planner-and-backend-boundary/spec.md 6.1·6.2·6.3; evidence/SIMULATION-REPORT.md

## Alternatives

2의 대안(부분 일치)은 진짜 작업을 삭제하므로 기각. 4의 대안(문자열 비교)은 충돌을 만들므로 기각. 3은 대안이 사실상 없다 — 거부하면 순차 작업이 진행 불가.
